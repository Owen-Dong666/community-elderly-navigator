# Mind+ V2 K10 积木搭建步骤

目标：让 K10 只负责“听命令、显示、播报、按键和 LED”，电脑端智能体负责查询资料与生成办事步骤。K10 不保存 API Key，也不直接请求模型。

## 一、新建工程

1. 打开 Mind+ V2，选择**上传模式**。
2. 在“扩展”中添加主控板**行空板 K10**。
3. 确认代码区出现“K10 主程序开始”、A/B 键、离线语音识别、语音合成、屏幕和串口 0 积木。
4. 工程最终保存为 `社区老人办事导航员-K10.mp`。

在“变量”分类依次创建下表变量，全部设为“适用于所有角色”：

| 用途 | 变量 | 初始值 |
|---|---|---:|
| 通信 | `rxLine` | 空文本 |
| 通信 | `computerReady` | 0 |
| 通信 | `frameOpen` | 0 |
| 通信 | `lastPingTime` | 0 |
| 按键 | `buttonAFlag` | 0 |
| 按键 | `buttonBFlag` | 0 |
| 显示缓存 | `mode` | 空文本 |
| 显示缓存 | `serviceName` | 空文本 |
| 显示缓存 | `stepNow` | 0 |
| 显示缓存 | `stepTotal` | 0 |
| 显示缓存 | `titleText` | 空文本 |
| 显示缓存 | `bodyText` | 空文本 |
| 显示缓存 | `helperText` | 空文本 |
| 执行缓存 | `speechText` | 空文本 |
| 执行缓存 | `ledIndex` | 0 |
| 内部解析 | `fieldText` | 空文本 |
| 内部解析 | `fieldChar` | 空文本 |

最后四个变量只用于逐字去掉 `SERVICE|`、`STEP|` 等协议前缀，不会显示给老人。检查：变量区应正好看到上表 19 个名字，大小写完全一致。

## 三、创建六个自制积木

### 1. `全部LED关闭`

| 项目 | 内容 |
|---|---|
| Mind+ 分类 | 自制积木、引脚 |
| 可见积木文字 | `全部LED关闭` |
| 参数 | 无 |
| 连接顺序 | 将 P0、P1、P2、P8、P9、P12 依次数字写出低电平 |
| 执行后变量 | 不修改变量 |
| 放置检查 | 临时调用一次，六个 LED 都应熄灭 |

### 2. `点亮地图地点(编号)`

| 项目 | 内容 |
|---|---|
| Mind+ 分类 | 自制积木、控制、运算、引脚 |
| 可见积木文字 | `点亮地图地点(编号)` |
| 参数 | 数字参数 `编号` |
| 连接顺序 | 先调用 `全部LED关闭`；再用如果/否则判断 1—6，分别把 P0/P1/P2/P8/P9/P12 写为高电平 |
| 执行后变量 | 不修改全局变量 |
| 放置检查 | 参数为 4 时只亮 P8；参数为 0 时全灭 |

### 3. `显示初始页`

| 项目 | 内容 |
|---|---|
| Mind+ 分类 | 自制积木、屏幕显示 |
| 可见积木文字 | `显示初始页` |
| 参数 | 无 |
| 连接顺序 | 清屏；依次显示“街坊办事小助手”“请先说你好小行”“再说想办的事情” |
| 执行后变量 | 不修改变量 |
| 放置检查 | 上传后屏幕三行文字完整可读 |

### 4. `发送查询(文字)`

| 项目 | 内容 |
|---|---|
| Mind+ 分类 | 自制积木、屏幕显示、串口、运算 |
| 可见积木文字 | `发送查询(文字)` |
| 参数 | 文本参数 `文字` |
| 连接顺序 | 显示“正在查询”；调用 `全部LED关闭`；串口 0 输出连接后的 `QUERY|` 与参数文字，并在末尾换行 |
| 执行后变量 | `computerReady` 保持原值，显示缓存不修改 |
| 放置检查 | 串口应形成一整行，例如 `QUERY|我想报名参加书法班` |

### 5. `处理电脑指令(一行)`

| 项目 | 内容 |
|---|---|
| Mind+ 分类 | 自制积木、控制、运算、变量、计时器 |
| 可见积木文字 | `处理电脑指令(一行)` |
| 参数 | 文本参数 `一行` |
| 连接顺序 | 按“六、串口接收与状态缓存”中的分支顺序判断；这里只写缓存变量，不直接刷新完整状态 |
| 执行后变量 | 根据收到字段更新连接、心跳或帧缓存 |
| 放置检查 | 只收到半帧时屏幕和 LED 不发生变化 |

### 6. `应用完整状态`

| 项目 | 内容 |
|---|---|
| Mind+ 分类 | 自制积木、屏幕显示、语音合成 |
| 可见积木文字 | `应用完整状态` |
| 参数 | 无 |
| 连接顺序 | 清屏；显示 `serviceName`、`stepNow/stepTotal`、`titleText`、`bodyText`、`helperText`；调用 `点亮地图地点(ledIndex)`；将中文语音合成语速设为 `1`；合成并播报 `speechText` |
| 执行后变量 | 将 `frameOpen` 设为 0 |
| 放置检查 | 屏幕、播报和地图地点必须来自同一帧 |

## 四、初始化积木组

放在“K10 主程序开始”下面，连接顺序不能交换：

1. 串口 0 波特率设为 `115200`。
2. 把 P0、P1、P2、P8、P9、P12 设为数字输出。
3. 调用 `全部LED关闭`。
4. 将 `computerReady`、`frameOpen`、`lastPingTime`、`buttonAFlag`、`buttonBFlag`、`stepNow`、`stepTotal`、`ledIndex`、`charIndex`、`fieldAfterSeparator` 设为 0；其余文本变量设为空文本。
5. 调用 `显示初始页`。
6. 中文单次语音识别时长设为 `10000` 毫秒。
7. 添加下表 ID 10—17 的命令词。
8. 中文语音合成语速设为 `1`。
9. 串口 0 输出 `HELLO|1` 并换行。
10. 进入“重复执行”主循环，每轮末尾等待 20 毫秒。

检查：刚上传时六灯全灭，初始页出现，串口第一条设备消息是 `HELLO|1`。

## 五、八个离线语音命令

先说唤醒词**你好小行**，再说命令词。Mind+ 命令词必须按表格填写带空格的拼音：

| ID | Mind+ 拼音命令词 | 传给 `发送查询` 的中文文字 |
|---:|---|---|
| 10 | `shu fa ban` | 我想报名参加书法班 |
| 11 | `tai ji quan` | 我想参加太极晨练 |
| 12 | `liang xue ya` | 哪里可以免费量血压 |
| 13 | `she bao` | 我想咨询社保 |
| 14 | `gao ling jin tie` | 我想咨询高龄津贴 |
| 15 | `lao ren zhu can` | 老人助餐点在哪里 |
| 16 | `shui dian bao xiu` | 家里水电坏了怎么报修 |
| 17 | `ban hu zhao` | 我想办理护照 |

在主循环中依次放八个“如果识别到命令 ID”分支，每个分支只调用一次对应的 `发送查询(文字)`。

检查：说“你好小行，书法班”后，串口发送 `QUERY|我想报名参加书法班`。

## 六、串口接收与状态缓存

主循环中先判断“串口 0 可读字节数大于 0”，读取一行到 `rxLine`，再调用 `处理电脑指令(rxLine)`。自制积木按下列顺序判断：

1. `READY|` 开头：`computerReady=1`，`lastPingTime=当前运行毫秒`，屏幕显示连接成功。
2. 完全等于 `PING`：更新 `lastPingTime`。
3. 完全等于 `STATE_BEGIN`：`frameOpen=1`，并清空本帧的文本和数字缓存。
4. 当 `frameOpen=1` 时解析 `MODE|`、`SERVICE|`、`STEP|当前|总数`、`TITLE|`、`BODY|`、`HELPER|`、`SPEAK|`、`LED|`，分别写入对应变量。
5. 完全等于 `STATE_END` 且 `frameOpen=1`：调用 `应用完整状态`。
6. `ERROR|` 开头：`frameOpen=0`，调用 `全部LED关闭`，显示错误文字，并以语速 1 播报错误文字。

不要在收到某个字段时立刻更新屏幕；只有 `STATE_END` 能应用完整状态。

## 七、主循环中的按键与心跳

每轮按以下顺序：

1. 如果 `buttonAFlag=1`：先清零，再从串口输出 `BUTTON_A` 并换行。
2. 如果 `buttonBFlag=1`：先清零，再从串口输出 `BUTTON_B` 并换行。
3. 读取并处理至多一行串口数据。
4. 如果 `computerReady=1` 且“当前运行毫秒 − `lastPingTime` 大于 5000”：将 `computerReady` 设为 0，调用 `全部LED关闭`，显示“电脑连接已中断”。
5. 检查 ID 10—17 的语音结果。
6. 等待 20 毫秒后进入下一轮。

### A 键事件

将 `buttonAFlag` 设为 `1`。

### B 键事件

将 `buttonBFlag` 设为 `1`。

## 八、搭建完成自检

- A/B 事件各只有一块变量赋值积木，耗时操作全部在主循环。
- 只有 `STATE_END` 分支会调用 `应用完整状态`。
- `LED|0` 会让六灯全灭，非法地点编号也全灭。
- 超过 5 秒没有 `PING` 会显示断线并熄灯。
- 未知服务“办护照”显示并播报“当前资料中没有这项信息，请向社区工作人员确认”，且六灯全灭。
