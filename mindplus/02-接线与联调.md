# K10、DFR1231 与地图 LED 接线及联调

## 一、安全准备

1. 拔掉 K10 的 Type-C 线后再接 LED。
2. 每个 LED 必须串联一个 **220—330 Ω** 限流电阻，不能把 LED 直接跨接在信号脚和 GND 之间。
3. LED 长脚为正极，接“引脚 → 电阻 → LED 正极”；短脚为负极，接**公共 GND**。
4. 六路 LED 必须与 K10/DFR1231 共地。
5. 使用能传数据的 **Type-C 数据线**直接接电脑，只有充电功能的线无法上传或通信。
6. 引脚以 DFR1231 丝印为准，不按导线颜色猜测。

## 二、六路地图 LED

| LED | 地图地点 | 信号引脚 | 串联电阻 | LED 正极 | LED 负极 |
|---:|---|---|---|---|---|
| 1 | 小区入口 | `P0` | 220—330 Ω | 经电阻接 P0 | 接公共 GND |
| 2 | 社区中心 | `P1` | 220—330 Ω | 经电阻接 P1 | 接公共 GND |
| 3 | 卫生站 | `P2` | 220—330 Ω | 经电阻接 P2 | 接公共 GND |
| 4 | 活动室 | `P8` | 220—330 Ω | 经电阻接 P8 | 接公共 GND |
| 5 | 服务大厅 | `P9` | 220—330 Ω | 经电阻接 P9 | 接公共 GND |
| 6 | 便民驿站 | `P12` | 220—330 Ω | 经电阻接 P12 | 接公共 GND |

通电前用手逐根核对：信号脚、限流电阻、LED 极性、公共 GND。

## 三、查找 K10 的 COM 端口

1. 暂时拔下 K10，在 Windows“设备管理器 → 端口（COM 和 LPT）”记住现有列表。
2. 用 Type-C 数据线插入 K10，列表中新出现的端口就是目标，例如 `COM5`。
3. 也可以在 Mind+ 连接设备窗口核对同一个 COM 号。
4. 把这个号码记在展示卡上；换 USB 口后号码可能变化。

## 四、固定的启动与上传顺序

### 1. 接线

按上表接好六路 LED，K10 直接用 Type-C 数据线连接电脑。

### 2. 启动电脑端智能体

在项目目录打开 PowerShell，课堂保底使用：

```powershell
$env:MODEL_PROVIDER="mock"
.\.venv\Scripts\community-navigator.exe
```

看到服务运行在 `http://127.0.0.1:8000` 后再继续。

### 3. 在 Mind+ 上传积木

1. 打开 `社区老人办事导航员-K10.mp`。
2. 选择正确 COM 端口并连接设备。
3. 点击上传，等上传成功。
4. 确认 K10 显示初始页，六个 LED 全灭。

### 4. 断开 Mind+ 串口

点击 Mind+ 的断开设备，并关闭串口监视器。Mind+ 可以保持打开工程，但不能继续占用该 COM 口。

### 5. 启动 Python 串口桥

新开一个 PowerShell，把 `COM5` 换成实际号码：

```powershell
.\.venv\Scripts\community-navigator-bridge.exe --port COM5
```

K10 发送 `HELLO|1` 后应收到 `READY|智能体已连接`；随后电脑每 2 秒发送一次 `PING`。

## 五、五项实体演示场景

1. **书法班**：说“你好小行”，再说“书法班”。屏幕显示报名步骤，扬声器播报，4 号活动室 LED 亮。
2. **按键**：按 A 重复当前步骤；按 B 前进。到最后一步后再按 B，屏幕显示结束，六灯全灭。
3. **量血压**：重新唤醒后说“量血压”，3 号卫生站 LED 亮。
4. **社保与助餐**：说“社保”应亮 5 号服务大厅；说“老人助餐”应亮 6 号便民驿站。
5. **安全边界**：说“办护照”，屏幕和播报必须提示“当前资料中没有这项信息，请向社区工作人员确认”，六灯全灭。

每项都要同时核对屏幕、播报和 LED，不只看其中一个。联调完成后再把 LED 固定到纸板地图。
